Entry for the [make.fun bounty "The Funniest AI Excuse"](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

`main.py` (stdlib-only Python) writes one line — the funniest excuse an AI
agent gives after failing a task — to `/output/entry.txt`. The program is
deterministic: every run writes the exact same bytes.

Run it with:

```sh
python3 main.py
```
